# 🚀 Evolution of Todo

### AI-Powered Intelligent Task Management Application

Evolution of Todo is an AI-powered task management application developed as part of Hackathon II. The project explores the evolution of a simple todo application into a modern productivity tool with intelligent task management capabilities.

The application combines traditional task management features with an **AI assistant that helps manage tasks**, making it easier for users to organize their work and stay productive.

🌐 **Live Demo:** [Evolution of Todo](https://hackathon-ii-evolution-of-todo-jade.vercel.app/)

💻 **GitHub Repository:** [Hackathon-II-Evolution-of-Todo](https://github.com/nazeenasif/Hackathon-II-Evolution-of-Todo)

---

## ✨ Key Features

### 🤖 AI Task Assistant

An AI-powered assistant designed to help users manage their tasks through intelligent interactions. It brings AI into everyday productivity and makes task management more convenient.

### ✅ Task Management

Create, organize, and manage tasks in one place.

### 🎯 Task Prioritization

Assign priorities to tasks to help focus on important activities.

### 🏷️ Task Categorization

Use tags to organize tasks and keep related activities together.

### 🔍 Search and Filtering

Find tasks quickly and filter them to focus on relevant work.

### 🔐 User Authentication

Sign-up and sign-in functionality provides users with an entry point to the application.

### 🌐 Live Web Application

Access the deployed application directly through your browser.

## 🚀 Getting Started

Follow these steps to obtain the source code and explore the project locally.

### Prerequisites

- Git
- The runtime and package manager required by the selected phase
- Any required environment variables or API credentials documented by that phase

### 1. Clone the repository

```bash
git clone https://github.com/nazeenasif/Hackathon-II-Evolution-of-Todo.git
```

### 2. Navigate to the project directory

```bash
cd Hackathon-II-Evolution-of-Todo
```

### 3. Choose a development phase

For example:

```bash
cd Phase-IV
```

You can select another phase depending on which implementation you want to explore.

### 4. Install dependencies and run the application

Follow the instructions in the selected phase's README or project configuration. Installation commands, environment variables, and startup procedures may differ between phases.

**Note:** AI functionality may require additional configuration, depending on the implementation.
