# 🚀 Evolution of Todo

> **From a simple to-do list to a modern task management application.**

Evolution of Todo is a project developed for Hackathon II, demonstrating the progressive development of a todo application across multiple phases. The project focuses on building practical software, improving task management, and exploring modern application development approaches.

🌐 **Live Demo:** [Try Evolution of Todo](https://hackathon-ii-evolution-of-todo-jade.vercel.app/)

💻 **GitHub Repository:** [Hackathon-II-Evolution-of-Todo](https://github.com/nazeenasif/Hackathon-II-Evolution-of-Todo)

---

## ✨ Features

The live application provides tools to organize and manage everyday tasks.

- ✅ **Task Management** — Manage your tasks in one place.
- 🎯 **Task Priorities** — Organize tasks according to their importance.
- 🏷️ **Tags** — Categorize tasks for easier organization.
- 🔍 **Search** — Find tasks quickly.
- 🔽 **Filtering** — Narrow down tasks to find what you need.
- 🔐 **User Authentication** — Sign up and sign in to access the application.
- 🌐 **Live Deployment** — Access the application through its online deployment.

*Features may vary across individual project phases.*

## 🛠️ Project Evolution

## 🚀 Getting Started

To explore the source code locally, follow these steps.

### Prerequisites

- Git
- The runtime and package manager required by the phase you want to run

### 1. Clone the repository

```bash
git clone https://github.com/nazeenasif/Hackathon-II-Evolution-of-Todo.git
```

### 2. Navigate to the project

```bash
cd Hackathon-II-Evolution-of-Todo
```

### 3. Explore a phase

Choose the phase you want to explore:

```bash
cd Phase-I
```

Replace `Phase-I` with `Phase-II`, `Phase-III`, or `Phase-IV` as appropriate.

### 4. Follow the phase-specific instructions

Check the selected phase's README, package configuration, and project files to determine the correct installation and run commands.
